# Nuni.sh

Static scan for leftover dev artefacts before pushing to prod. Detects:

- **AI artefacts** (`--ai`): zero-width / invisible Unicode characters, homoglyphs (Cyrillic/Greek/fullwidth impersonating ASCII, e.g. Latin `a` vs Cyrillic `а`), bidirectional control characters (Trojan Source, CVE-2021-42574), soft hyphens / non-breaking spaces, smart quotes / typographic dashes, AI placeholder markers ("As an AI", "Generated by ChatGPT", "AI response will be inserted", ...), LLM boilerplate ("I hope this helps", "as of my knowledge cutoff", ...), and AI attribution/disclaimers ("This code was generated with the assistance of AI")
- **Code smells** (`--code`): comments (TODO/FIXME/HACK/XXX/BUG/NOTE/PLACEHOLDER), leftover debug (console.log, debugger, commented-out code), placeholder git clones ("git clone <this-repo>", "github.com/your-username" - typical AI docs), and security (API keys, passwords, secrets, bearer tokens, AWS keys, embedded private keys)
- **Formatting** (`--format`): tabs, leading tabs, trailing whitespace, 3+ consecutive empty lines, overlong lines (>80), non-ASCII characters, Windows CRLF line endings, BOM
- **Hardcoded values** (`--path`): absolute Unix paths, home-dir paths, env-var paths, URLs, localhost, IP addresses
- **Copyright/licensing** (`--license`): placeholder copyright headers ("Copyright (c) Your Name", `© <author>`, ...) and copyright years in the future (a classic AI hallucination). Pair with `--copyright NAME` to also flag missing headers.

Findings are grouped by severity (CRITICAL/ERROR/WARNING/INFO) with hit counts, then summarised in a per-type and per-severity listing.

## Usage

```bash
./Nuni.sh [OPTIONS] [DIRECTORY] [FILE_PATTERN]
```

```bash
./Nuni.sh                                # scan current directory, all profiles
./Nuni.sh --ai                           # only AI-artefact checks
./Nuni.sh --code --format                # combine profiles
./Nuni.sh --path src/ "*.py"             # scan src/, only .py files
./Nuni.sh --strict                       # exit 1 if any issue is found (for CI)
./Nuni.sh -v                             # show every matching line, not just the first 5
./Nuni.sh --copyright "Your Name"        # also flag files missing a copyright header
./Nuni.sh -l                             # list all detection rules and exit
./Nuni.sh -c                             # disable colored output
./Nuni.sh --no-exclude                   # also scan build/artifact/hidden folders
```

Profiles (default: `--all` when none are given):

| Flag | What it scans |
|---|---|
| `--ai` | Invisible Unicode, homoglyphs, bidi control, soft hyphens/NBSP, smart quotes/dashes, AI placeholders, AI attribution |
| `--code` | Comments, leftover debug, placeholder git clones, security secrets |
| `--format` (alias `--style`) | Whitespace, line length, CRLF, BOM, non-ASCII |
| `--path` | Hardcoded paths, URLs, IPs, env-var paths |
| `--license` | Placeholder copyright headers, future copyright years |
| `--all` | Every profile |

## Exclusions

By default the scanner **prunes build/artifact/VCS/dependency directories and
hidden (dot) folders** (`.git`, `node_modules`, `__pycache__`, `target`, `bin`,
`obj`, `build`, `dist`, `.FOLDER`, `.venv`, ... - see the `EXCLUDE_DIRS`
variable at the top of the script; hidden dot folders such as `.FOLDER` are
pruned via the generic `*/.*` rule even though they are not listed there).
Use `--no-exclude` to scan them anyway.

Some file formats are **never scanned, even with `--no-exclude`**: binary,
image, media, archive, font and database files (see `EXT_EXCLUDE`). This is
enforced twice - by extension in `find` and as a backstop with `file(1)`
(anything not identified as text is skipped, so a PNG renamed without an
extension is still ignored). Hidden *files* such as `.env` are still scanned.

## Fixtures

- `test_sample.txt` - formatting issues (tabs, long lines, non-ASCII, ...)
- `test_ai_artefacts.txt` - AI-generated leftovers, secrets, debug code
- `test_unicode_artefacts.txt` - invisible Unicode, homoglyphs, bidi, soft hyphens/NBSP, smart quotes/dashes
- `test_copyright_artefacts.txt` - placeholder copyright, future copyright year, AI attribution
- `test_clean.txt` - a clean file that must produce no findings

These are intentional, so they are *not* meant to be "clean".

## Implementation

| | |
|---|---|
| Dependencies | `bash`, `grep -P` (PCRE with UTF-8 support), `file`, `od`, `sed`, `awk`, `date` (copyright-year check) |
| Detection rules | `PATTERNS` array near the top of the script. Format: `name\|description\|severity\|profile\|regex` - the regex is the **last** field so it may contain `\|` freely. Edit there to add/remove rules. |
| Character classes | `C_ZW`, `C_BIDI`, `C_SOFT`, `C_TYPO`, `C_HOMO` define the Unicode ranges for the AI-artefact rules (PCRE `\x{...}` syntax) |
| Display cap | `MAX_LINES_PER_PATTERN` (default 5, unlimited with `-v`) caps matching lines shown per rule |
| Special cases | BOM (byte detection via `od`), line length (read loop with overflow info), 3+ empty lines (awk) |

Each file is matched against every active rule with `grep -P`. Results are grouped by severity with hit counts; `--strict` turns findings into a non-zero exit code for CI gating.
