# Bash as Shortcuts

An holder for bash commands and scripts I find useful. Each subdirectory is a standalone tool with its own README.

| Repo | tldr |
|---|---|
| [`calltree/`](calltree/) | "Google Map for devs" map codebases into mermaid/dot format |
| [`docs/`](docs/) | Terminal reference for x86 asm, SIMD intrinsics, and (optionally) C++ stdlib docs |
| [`fork/`](fork/) | Shortcut to clone a fork and wires it to the `upstream` remote in one call |
| [`gittraffic/`](gittraffic/) | Tracks clones/unique cloners for your GitHub opened repos over time |
| [`Nuniform/`](Nuniform/) | Static scan for leftover dev artifacts (secrets, debug prints, TODOs) before pushing |
| [`watchcub/`](watchcub/) | Setting up favorable kernel settings to run benchmark + telemetry |
| [`spotify/`](spotify/) | UI-less spotify, reducing CPU usage when doing benchmarks while keeping music |
